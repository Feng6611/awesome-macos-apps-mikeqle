# Contributing

Thanks for helping keep this list useful. Please read this before opening a pull request. A PR that skips it may be closed with a link back here.

## What gets in

An app is added when all of these are true:

- **It runs on macOS.** Native apps are preferred. Cross-platform apps are fine if they're well supported on the Mac.
- **It's maintained.** It has had a release in the last two years, and its website or repository is up.
- **It's useful to a general Mac user or a developer,** and it does something the apps already listed don't do as well.
- **It's not a thin wrapper** around a website or a chatbot API.
- **Its link has no referral codes or tracking parameters.**

Being listed is not an endorsement, and leaving an app out is not a judgement on it. The maintainer may decline an entry that meets the rules if the section already covers it well.

## Format

One line per app, in the right section, in alphabetical order (ignoring case):

```markdown
- [App Name](https://example.com/) - What it does, in one factual sentence. 🆓 [🔓](https://github.com/owner/repo)
```

- **The description is one sentence that ends with a full stop.** Say what the app does. Leave out adjectives such as "best", "powerful" or "beautiful", and don't start with "A" or "An".
- **Price markers:** 🆓 if it's free; 🔹 if it has a free plan with a paid upgrade; no marker if it's paid (with or without a trial).
- **Open source:** add 🔓 linked to the source code, if the code is public.
- **The main link** goes to the app's own website, or to its repository if it has no website.

## Pull requests

- **One app per pull request.** Title it `Add <App Name>` (or `Update <App Name>` or `Remove <App Name>`).
- **If you make the app, say so in the pull request.** Makers are welcome, but the entry follows the same rules as everything else.
- **Corrections are as welcome as additions:** a changed price, a moved website, an app that's no longer maintained.

## How the list is kept current

- A workflow checks every link once a week and on every pull request.
- Apps with no release in two years are removed. They can come back when they're updated again.

## Code of conduct

Be kind and assume good faith. Disagreements about an entry are settled in the pull request, on the facts.
